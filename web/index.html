怎么用

1. 让它听见你

点右上角「开启麦克风」并允许权限。建议戴耳机，避免外放串进麦克风。

2. 录入参考人声 → 只看三样

点「录入参考人声」清唱/朗读一段，点「停止录音」后自动解析。结果只显示三块：什么调（C 大调 / A 小调 …）、歌词（可编辑，每行一句）、简谱（每个字的音符与节拍）。

3. 练唱：像 K 歌一样

点「练唱开始」后有 3-2-1 倒计时，然后逐字高亮：能看到每个字的歌词、简谱音符、几拍，跟着唱。唱完点「停止录音」。

4. 结果：一篇歌词，上下两排

结果显示整篇歌词。每个字上下两排：上排原唱简谱、下排你唱的简谱，并标出「偏高 / 偏低 / 快了 / 慢了 / 没唱到」。句末还有一句小结，比如「一闪一闪偏高、亮晶晶偏慢」。

5. 历史任意互比

每次录音都进右侧「我的录音」。点一条设为 A 参考，再点另一条设为 B 对比，点「对比这两段」——任意两段人声都能互相当标准比。

说明

歌词文本不是语音识别出来的；这里对比的是纯人声旋律本身（音高 + 节奏）。所有音频只存在这台电脑的浏览器里，不上传。
