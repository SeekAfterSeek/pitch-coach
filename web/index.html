怎么用

1. 让它听见你

点右上角「开启麦克风」并允许权限。建议戴耳机，避免外放串进麦克风。

2. 录入参考人声

点「录入参考人声」，清唱/朗读任意一段（不用伴奏）。点「停止录音」后系统会自动解析这段人声——提取出每个音符的音高和节奏，作为对照的「谱」。

3. 练唱 + 对比

解析完成出现「练唱开始」。点它，再清唱一遍；唱完点「停止录音」，系统自动把这一遍和参考对齐并对比：总分、准音率、覆盖度，以及逐音符「偏高/偏低/准、快了/慢了/没唱到」。

4. 历史任意互比

每次录音都进右侧「我的录音」。点一条设为 A 参考，再点另一条设为 B 对比，点「对比这两段」——任意两段人声都能互相当标准比。也可以导入本地音频文件。

说明

歌词文本不是语音识别出来的；这里对比的是纯人声旋律本身（音高 + 节奏）。所有音频只存在这台电脑的浏览器里，不上传。
