怎么用

1. 让它听见你

点右上角「开启麦克风」并允许权限。建议戴耳机，避免外放串进麦克风。

2. 录入参考人声 → 边听边核对

点「录入参考人声」清唱/朗读一段，点「停止录音」后自动解析。解析卡里：什么调（C 大调 / A 小调 …）、歌词（可编辑）、简谱、逐字对应格。点 「▶ 播放我刚录的原声」，原声唱到哪个音符，简谱和逐字格就会亮起那一格，一眼看清字落在哪个音上。

3. 改歌词 → 重新解析匹配 → 确定

在歌词框里改字（或粘贴整段）后，点 「🔄 重新解析匹配」：会拿第一次录音解析出的节奏骨架，把歌词按每句实际演唱时长重新分句、逐字钉回每个音符。下面的「逐字对应格」可以点单个格子改那个音符上的字。核对无误点 「✓ 确定歌词」 锁定。

4. 练唱：像 K 歌一样

点「练唱开始」后有 3-2-1 倒计时，每句起音前也会给「第 N 句 · 3-2-1 这一句开始」提词； 然后大字歌词逐字高亮——当前字是白底发光的大字，一眼锁定唱到哪； 音符（简谱+节拍）以小字垫在歌词上方作提示，不抢歌词的视线。 唱完点「停止录音」。

5. 结果：小鸟音符对照 + 一篇歌词

结果区上半是小鸟音符图：每个音符一只小鸟，飞得越高音越高，鸟身上写着简谱—— 青色是原唱鸟、绿色是你唱的鸟。两只鸟碰到一起会开出一朵 🌸 花 = 又准又稳； 上下分开 = 偏高 / 偏低（缝隙越大差得越多），左右错开 = 快了 / 慢了； 鸟后的云彩 = 这个音的气息长度（按拍子拉长，你的云短了就是气息短、长了就是拖了）；🫥 = 没唱到。 点小鸟反复听那一个音；点「▶ 参考 / ▶ 这次」播放录音时，当前的小鸟会亮起来。 下半还是那篇上下两排的歌词（原唱简谱 / 你唱简谱 + 高低快慢标注）。

6. 历史任意互比

每次录音都进右侧「我的录音」。点一条设为 A 参考，再点另一条设为 B 对比，点「对比这两段」——任意两段人声都能互相当标准比。

说明

歌词可自动识别、手动填写、按节奏重排、逐格修改，最终由你「确定」；对比的是纯人声旋律本身（音高 + 节奏）。所有音频只存在这台电脑的浏览器里，不上传。
