教唱模式（录入人声 → 清唱跟练）

先录一段纯人声作为参考（它会自动解析出每个字的音高与节奏），再填歌词、对齐，然后清唱跟练，逐字点评「高了 / 低了 / 准、快了 / 慢了 / 没唱到」。

关于

音高检测：YIN 算法（de Cheveigné & Kawahara, 2002），FFT 加速，纯前端运行。
评分模型：容差分档 + 覆盖度 + 稳定性加权。

怎么用

1. 让它听见你

点「开启麦克风」。浏览器会请求权限。建议戴耳机——外放会让参考音被你自己的麦克风收进去，干扰判断。

2. 选一首歌

内置了六首公有领域练习曲。要唱自己的歌，去「曲库」导入：音频文件会被提取主旋律作为参考线，MIDI 文件则直接读音符。

3. 看懂卷帘

灰色横条是原唱的音高位置，也就是「应该唱在哪」。彩色光带是你的声音。绿色=在容差内，黄=略偏，橙=跑调，红=差很远。竖虚线是「此刻」。

4. 表盘

指针居中=准。往左=唱低了（flat），往右=唱高了（sharp）。下面的数字是偏差音分，100 音分=一个半音。

5. 录音复盘

录完去「录音复盘」，能看到整首歌的轨迹、每一句得分、平均值偏差、稳定性。几条录音会按总分排序，直接看出哪次最准。

6. 延迟

如果发现你的线条总是领先或落后于灰条，调「延迟补偿」。戴蓝牙耳机通常需要 +100～200ms。
